# BHS/PBB/PBB부대설비 동향 조사 — 2026-08-10 (월) 베이스라인

없어 전량 기록하며, 다음 실행부터는 신규/변동 항목만 채팅으로 보고한다.

- 카테고리 1: BHS (Baggage Handling System)
- 카테고리 2: PBB (탑승교 본체)
- 카테고리 3: PBB 부대설비 (PC-Air, PWS, AC-GPS)
- 각 카테고리 내 순서: 장애사례(중요도순) → 신기술 동향(중요도순)

전체 항목과 요약, 출처 링크, 설계 주안점은 동일 실행 회차의 채팅 응답(및
이메일/알림 발송분)에 기재됨. 상세 서술은 채팅 기록을 참조. 이 파일은 `id`,
`title`, `date`, `importance`, `url`, `first_seen` 필드로 향후 회차의 diff
기준점 역할만 한다 (본문 요약은 `trend_ledger.json`이 아닌 대화 기록에 있음을
참고할 것).

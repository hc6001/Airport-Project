# Airport-Project — BHS/PBB 글로벌 동향(사고·신기술) 추적 저장소

전세계 공항의 **수하물처리시설(BHS)**·**탑승교(PBB)**(및 PBB 부대설비: PC-Air, PWS, AC-GPS)
관련 **사고/장애 사례**와 **신기술 동향**을 주기적으로 조사해 채팅으로 보고하는 Claude 정기 실행(루틴)의
**상태 저장소(state store)** 입니다.

이 폴더는 저장소 루트의 `ledger.json`(입찰공고 트래커, 별도 루틴)과는 **다른 루틴**을 위한 것입니다.

## 파일 구조
- `ledger.json` — 이미 보고한 모든 사례의 기계판독용 원장(id·구분·제목·날짜·링크·first_reported)
- `reports/` — 실행일자별 스냅샷 보고서(사람이 읽는 마크다운, 실제 채팅 답변 내용을 기록)

## 스크리닝 규칙
- 사고: BHS 또는 PBB(부대설비 포함) **자체의 결함/오작동으로 인해** 승객·항공사·공항 운영에 실질적 피해(지연·결항·부상·수하물 미탑재 등)를 유발한 경우만 포함. 통계성 자료·단순 계획 발표는 제외.
- 신기술: 국가정책, 제작사 기술개발, 실제 공항 활용사례, 이용객 만족도 관련.
- 넘버링: 1번대=BHS, 2번대=PBB(본체), 3번대=PBB 부대설비(PC-Air/PWS/AC-GPS).
- 정렬: 공항 설계 업무에서 감안할 내용이 많은 순(중요도순).
- **매 실행마다 `ledger.json`을 먼저 대조하여, 이미 보고되어 변동 없는 항목은 재보고하지 않음.**
- 매주 금요일에는 그 주(월~금) 동안 새로 확인된 항목만 집계해서 별도로 정리.

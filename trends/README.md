# Airport-Project — BHS / PBB 사고·신기술 동향 트래커

전세계 공항의 **수하물처리시설(BHS)**과 **탑승교(PBB, PC-Air/PWS/AC-GPS 부대설비 포함)**에서
발생한 **장애·사고 사례**와 **신기술 동향**(정책·제작사 개발·실제 활용사례·이용객 만족)을
주기적으로 조사하는 Claude 정기 실행 루틴의 상태 저장소입니다.

이 디렉터리는 저장소 루트의 `ledger.json`(입찰 추적용)과는 **별개 목적**입니다 — 이쪽은
사고/기술 동향, 루트는 조달·입찰 추적입니다.

## 파일 구조
- `ledger.json` — 지금까지 보고한 모든 사례의 기계판독용 원장(key·section·type·date·link·first_seen/last_updated)
- `reports/` — 각 실행일자별 스냅샷 보고서(사람이 읽는 마크다운, 한국어)

## 넘버링/섹션 규칙
- 1 = BHS, 2 = PBB(본체), 3 = PBB 부대설비(PC-Air/PWS/AC-GPS)
- 각 섹션 내에서 장애발생 사례를 먼저, 신기술 동향을 뒤에 배치
- 중요도(공항 설계 시 고려사항의 양) 순으로 정렬

## 운영 규칙
- 매 실행마다 `ledger.json`을 읽고 대조해 **변동분(신규 사례·업데이트)만** 보고, 과거와 동일한 내용은 생략
- 매주 금요일에는 그 주에 새로 발견된 항목을 모아 주간 종합으로 보고
